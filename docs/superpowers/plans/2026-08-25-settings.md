# Shadercraft Settings Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a truthful fifth-tab Settings experience with durable device preferences, editor and preview controls, account/sync status, single-sketch export, safe diagnostics, and public help/about actions.

**Architecture:** A versioned AsyncStorage repository and root provider own device-only preferences. Existing editor and shader components consume narrow settings values, while focused export and diagnostics services isolate native APIs from the Settings screen. The screen composes existing auth, sync, data, and profile state without duplicating their behavior.

**Tech Stack:** Expo SDK 57, Expo Router, React Native 0.86, React 19.2, AsyncStorage, Expo GL, Expo FileSystem, Expo Sharing, Expo Application, Expo Device, Expo Clipboard, TypeScript, Jest, Testing Library.

**Spec:** `docs/superpowers/specs/2026-08-25-settings-design.md`

## Global Constraints

- Read the exact Expo SDK 57 documentation at `https://docs.expo.dev/versions/v57.0.0/` before changing Expo code.
- Settings is the fifth root tab after Home, Course, Practice, and Editor; its label remains visible.
- Device settings are not profile-scoped and never sync.
- Defaults are font size `14`, line numbers enabled, Full speed, and responsive editor preview mode.
- Battery saver targets approximately 30 presented frames per second without slowing shader time.
- Export exactly one active-profile sketch per action; native output contains source only and ends in `.frag`.
- Never place email, identifiers, tokens, URLs/keys, shader source, sketch names, progress, paths, database contents, or free-form logs in diagnostics.
- Cloud-disabled builds remain fully offline and never construct or contact Supabase.
- Do not add subscriptions, GLSL selection, resolution scaling, 120 FPS, IntelliSense, word wrap, syntax themes, optional autosave, appearance customization, cache clearing, bulk ZIP export, import, cloud sketch sync, broad reset, or analytics.
- Follow TDD: observe each new test fail for the intended reason before production changes.
- End every task with a focused review and one commit.

## File Structure

- `src/data/settings/device-settings.ts` — settings types, defaults, validation, migration, serialized repository.
- `src/context/settings-context.tsx` — hydration, optimistic updates, persistence rollback, React access.
- `src/data/settings/frame-scheduler.ts` — pure decision helper for Full speed and Battery saver.
- `src/data/settings/sketch-export.ts` — filename sanitization and platform-neutral export orchestration.
- `src/data/settings/sketch-export.native.ts` — Expo FileSystem/Sharing adapter for Android and iOS.
- `src/data/settings/sketch-export.web.ts` — browser download adapter for the static web build.
- `src/data/settings/diagnostics.ts` — explicit diagnostic allowlist and text formatter.
- `src/app/settings.tsx` — Settings composition, sections, chooser, diagnostics preview, and feedback.
- `.github/ISSUE_TEMPLATE/bug_report.yml` — public bug form.
- `.github/ISSUE_TEMPLATE/feature_request.yml` — public feature form.

Existing files change only at their current boundaries: `_layout.tsx` provides settings; bottom navigation adds the root; `GlslInput` accepts typography props; `ShaderSandbox` reads performance; Editor uses the provider for preview mode; Course loses its account shortcut; README documents the behavior.
